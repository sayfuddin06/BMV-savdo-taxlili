# BMW Sales Analytics Dashboard

## Executive Summary

This project presents a professional **BMW Sales Analytics Dashboard** developed in **Power BI** to analyze BMW vehicle sales performance, revenue trends, regional market distribution, pricing metrics, and model-level sales insights.

The dashboard transforms automotive sales data into actionable business intelligence insights, enabling users to evaluate:

* BMW sales performance
* Revenue generation
* Model popularity
* Regional sales trends
* Vehicle pricing analytics
* Fleet composition insights

The solution was designed to simulate a real-world automotive sales intelligence and executive reporting system used by premium vehicle manufacturers.


---

# Business Problem

Automotive companies manage massive sales datasets across:

* Vehicle models
* Global markets
* Pricing categories
* Sales regions
* Fuel types
* Performance segments

Without centralized analytics, monitoring sales performance and identifying market trends becomes difficult.

This dashboard solves that challenge by providing an interactive and executive-level BMW sales analytics platform.

# Dataset Information

The dataset contains BMW sales and vehicle information including:

| Column              | Description                  |
| ------------------- | ---------------------------- |
| Model               | BMW vehicle model            |
| Sales               | Total units sold             |
| Revenue             | Revenue generated            |
| Price               | Average vehicle price        |
| Mileage             | Average mileage              |
| Region              | Sales region                 |
| Fuel_Type           | Electric, Hybrid, or Petrol  |
| Performance_Segment | Vehicle performance category |
| Year                | Sales year                   |
